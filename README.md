# India ResQNet

AI-Powered Multi-Agent Disaster Response & Resource Intelligence Platform.

## Features

- Disaster command center dashboard
- AI risk analysis simulation
- Incident prioritization
- Resource availability
- GIS-style situation map
- Rescue team and ambulance monitoring
- AI recommendations
- Flask Python backend
- Responsive UI

## Run locally

### 1. Open terminal in this folder

```bash
pip install -r requirements.txt
```

### 2. Start the server

```bash
python app.py
```

### 3. Open in browser

```text
http://127.0.0.1:5000
```

Click **Simulate Disaster** to demonstrate the working prototype.
